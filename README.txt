دوريّة v3 — واجهة مطوّرة للتجربة

المضاف: تصميم زجاجي ناعم، شريط تنقل Liquid Glass، أيقونة مسطّحة أقرب للـ 2D، شاشة حساب، تسجيل دخول وإنشاء حساب (واجهة تجريبية فقط)، واختيار العملة لكل التزام وملخص تجهيزات الشهر حسب العملة.

مهم: تسجيل الدخول غير مربوط بخادم ولا ينشئ حسابًا حقيقيًا. لا تدخل كلمة مرور حقيقية. الإشعارات الشهرية التلقائية والمزامنة السحابية لم تُنفذ بعد. البيانات محلية في المتصفح.

النشر: ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages بدل الملفات القديمة.
