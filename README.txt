دوريّة — نموذج أولي تفاعلي

الموجود:
- واجهة عربية RTL باللون الأزرق #2857F7 وبيضاء.
- شاشة رئيسية، قائمة الالتزامات، إضافة اشتراك/قسط، تقويم، ومساعد تجريبي.
- حفظ البيانات محليًا في المتصفح (localStorage).
- أيقونة تطبيق وملفات PWA أولية.

مهم:
- هذا نموذج أولي، وليس تطبيقًا منشورًا أو مستضافًا.
- لا توجد تذكيرات تلقائية أو مزامنة أو ذكاء اصطناعي حقيقي بعد.
- لكي تظهر كأيقونة على iPhone بشكل موثوق، يلزم رفع الملفات إلى استضافة HTTPS ثم فتح الرابط في Safari واختيار Share > Add to Home Screen.
- فتح index.html مباشرة يسمح بتجربة الواجهة في بعض المتصفحات، لكن خصائص PWA تتطلب استضافة HTTPS.
